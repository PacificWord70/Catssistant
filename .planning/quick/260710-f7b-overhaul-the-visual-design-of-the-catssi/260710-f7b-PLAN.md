  <name>Task 1: Retune the design foundation — tokens, soft shadows, display font, and canvas</name>
  <files>tailwind.config.ts, app/layout.tsx, app/globals.css</files>
  <action>
This is the high-leverage change: because nearly every component references `brand-*` utility classes, retuning the token values here propagates the new palette across the whole app automatically.

In tailwind.config.ts (`theme.extend`):
- Replace the six `brand` color VALUES with the "Soft Modern Warmth" palette, keeping the NAMES exactly: cream `#FFFBF6`, tan `#E7C9A9`, brown `#6B4A34`, orange `#F26A1B`, slate `#5F8AA8`, charcoal `#2B2622`.
- Add a `boxShadow` block under `extend` with two diffuse, low-opacity tokens: `soft` set to `0 2px 12px -2px rgba(43, 38, 34, 0.08)` and `card` set to `0 6px 24px -6px rgba(43, 38, 34, 0.12)`. These become `shadow-soft` and `shadow-card` utilities used in Tasks 2 and 3.
- In `fontFamily.display`, change the leading CSS variable from `var(--font-tapestry)` to `var(--font-display)` and keep the serif fallbacks. Leave `fontFamily.sans` (Figtree) unchanged.

In app/layout.tsx (font import swap only — do NOT touch NavBar, CatWalker, metadata, or the JSX structure):
- Replace the `Tapestry` import from `next/font/google` with `Fraunces`. Configure Fraunces with `subsets: ['latin']`, `variable: '--font-display'`, `display: 'swap'`, and a weight range appropriate for headings (e.g. `weight: ['400','500','600']`). Keep the Figtree config as-is (`--font-figtree`).
- Update the `<html>` element's `className` template literal so it exposes the new `--font-display` variable instead of the old Tapestry variable (swap `${tapestry.variable}` for the new Fraunces variable binding). Body className stays `text-brand-charcoal font-sans min-h-screen`.

In app/globals.css:
- Change the `body` `background-color` from `#F7BAD2` to `#FBECF2` (soft milky pink — retains the pink charm at modern saturation).
- Add `-webkit-font-smoothing: antialiased;` and `text-rendering: optimizeLegibility;` to the `body` rule for cleaner type on the warm canvas.
- Leave the `@tailwind` directives and the `catWalk` keyframes + `.animate-cat-walk` rule completely untouched.

No logic, no new dependencies (Fraunces ships via next/font/google), no route or data changes.
