# Quick Task: Health page — weight over time

Start of the Health Home page: a weight-over-time chart plus summaries drawn
from the health data already in the app.

## The blocker this has to clear first

`Cat.weight` is a **single scalar** per cat — the current weight on the profile.
A time series needs many dated measurements, so there is nothing to plot today.

`types/healthRecord.ts` already models exactly the missing piece and is
completely unused — no storage, no slice, no UI references it. Its own doc
comment anticipates this chart. So the work is to make that type real, not to
design something new.

## Decisions

**1. `Cat.weight` stays the profile's current weight; `HealthRecord` is the
history.** Logging a weight writes a record *and* updates `Cat.weight`, so the
profile and card stay correct and nothing existing breaks. Reversible: if the
records should later become the sole source of truth, `Cat.weight` becomes a
derived read.

**2. The existing profile weight is NOT back-filled as a chart point.** We know
the number but not the date it was taken. Putting it on a time axis would mean
inventing a measurement date, which is fabricated data. Cats with a weight but
no records show the number as a stat and an empty chart inviting the first log.

**3. No charting dependency.** Dependencies need team discussion (CLAUDE.md), and
the repo already draws its own graphics. The chart is hand-rolled SVG.

**4. No breed-typical weight baseline.** `lib/breeds.ts` carries energy,
friendliness, grooming and vocality — no weight. Comparing against a healthy
range would mean inventing veterinary data, so the chart shows the cat's own
trend only.

## Scope

- `lib/healthStorage.ts` — HealthRecord CRUD in localStorage, SSR-guarded, same
  shape as `lib/storage.ts`
- `store/healthSlice.ts` — wired into `store/index.ts` as a fourth slice; reads
  and writes stay in thunks, reducers pure
- `lib/healthAnalysis.ts` — pure helpers: chart scaling, trend between first and
  last, series sorting. Pure so the Vitest suite can reach it
- `components/WeightChart.tsx` — SVG line chart, brand tokens, no deps
- `components/WeightLogForm.tsx` — modal to log a dated weight
- `app/health/page.tsx` — cat picker, chart, stats, replacing the placeholder
- `lib/healthAnalysis.test.ts` — covers the maths

Summaries come from data that already exists: last vet visit and active
medications from schedule events, known illnesses from the profile.

## Out of scope

Editing/deleting past records, multi-cat comparison, other metrics on
`HealthRecord`, exporting health data. Note if this grows further it deserves a
real roadmap phase rather than another quick task.

## Verification

`typecheck`, `lint`, `npm test` green; page renders with no console errors;
chart correct with 0, 1 and many records.
